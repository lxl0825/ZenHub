## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/ZenHub.git`
2. `cd ZenHub`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ZenHub, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
